Network Activity

ZERO network calls during normal operation.

Component-by-component analysis:
  • Main compositor: Zero networking. Only renders, manages windows, and handles input.
  • hyprctl: Local Unix socket IPC only — AF_UNIX at /run/user/<uid>/hypr/<instance>/.socket.sock
  • hyprpm (plugin manager, separate binary): Uses git clone only on explicit user command with Y/n confirmation prompt. Never runs automatically.

No telemetry. No analytics. No phone-home. No update checker.

Crash Reporter Analysis

Writes to LOCAL FILE ONLY.

  • Output path: $XDG_CACHE_HOME/hyprland/hyprlandCrashReport<pid>.txt
  • NO network transmission. The crash report is a local text file only.
  • Can be disabled entirely: HYPRLAND_NO_CRASHREPORTER=1
Telemetry controversy: Investigated thoroughly — ZERO telemetry code exists in the current codebase. Past rumors were unfounded. No analytics, no data collection, no remote reporting of any kind.

Privilege Requirements

Runs as a regular user. Accesses GPU via DRM/KMS and input devices via libinput — standard for any Wayland compositor. No root privileges required.

Security Concerns

  • None critical.
  • hyprpm (plugin manager) does git clone but only on explicit user command with confirmation — acceptable UX pattern
  • Tracy profiler is opt-in only (disabled by default) — no risk in normal builds
  • 36.6k stars = extremely high community scrutiny
  • Crash reporter is local-only, can be disabled via environment variable
