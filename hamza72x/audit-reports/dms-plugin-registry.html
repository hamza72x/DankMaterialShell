Purpose

Official registry of plugins and themes for DankMaterialShell. A git repository containing plugin metadata in JSON manifest format, theme definitions (color schemes in JSON), CI validation scripts, and a Nix packaging layer. Serves as the directory for discovering and installing community plugins.

Language & Ecosystem

Content Type
JSON manifests (data-only), PNG screenshots, CI scripts (Python, GitHub Actions only)

Installation
Cloned via git to ~/.local/share/dms/registry/
Plugin Manifest Schema
Each plugin is a JSON file: { id, name, capabilities, category, repo, author, description, dependencies, compositors, distro, screenshot }

Network Activity

The registry itself makes no network calls. It is fetched via git clone / git pull from GitHub. All URLs in plugin manifests point to GitHub/GitLab/Codeberg repos.

Red Flag Checks

  • Executable scripts hidden in repo? NO — .github/ scripts are CI-only (validation, README generation)
  • Post-install hooks or lifecycle scripts? NO — no package.json, no install scripts in manifests
  • URLs pointing to malicious downloads? NO — all point to GitHub/GitLab/Codeberg repos
  • Shell commands embedded in manifest files? NO — JSON contains only declarative data
  • Binary files? NO — only PNG images in assets/
  • Nix packaging: explicitly dontConfigure = true; dontBuild = true; (copy-only, no execution)

Privilege Requirements

None. The registry is cloned and read as a regular user. No elevated privileges required.

Security Concerns

  • None critical.
  • Third-party plugin code is NOT audited by the registry — the registry is just a directory. Security of installed plugins depends on each plugin author.
  • CI scripts (Python validators) run only in GitHub Actions, never on user machines.

Verdict

SAFE

A clean, data-only registry containing pure JSON manifests, PNG screenshots, and CI validation scripts. Zero executable code that runs on user machines. No post-install hooks, no embedded commands, no malicious URLs. The Nix derivation explicitly disables all build steps (copy-only). Safe to use as a plugin/theme directory.
