Purpose

A full-featured Linux desktop shell providing a status bar, control center, notification system, and plugin framework. Built on Quickshell (QML) with a Go backend for system integration.

Language & Ecosystem

Languages

Build System
Go modules, built from source

Network Activity

The following external network calls were identified:

  • GitHub API — version check (HTTPS)
  • ip-api.com — geolocation for weather widget (HTTP)
  • api.danklinux.com — plugin metadata, GET-only (HTTPS)
  • open-meteo.com — weather data (HTTPS)
  • nominatim.openstreetmap.org — reverse geocoding (HTTPS)

No telemetry, no analytics, no data exfiltration detected. All calls are for user-facing features.

Privilege Requirements

Uses sudo / doas / run0 via the internal privesc package. This is standard and expected for system package management operations (installing/removing packages). Privilege escalation is user-initiated only.

All external program execution targets standard Linux system tools: pacman, apt, dnf, systemctl, etc.

Security Concerns

  • Minor: ip-api.com is accessed over HTTP, not HTTPS. This is a privacy risk (ISP/network can see geolocation request) but not a direct security vulnerability.
  • Minor: Plugin feedback API at api.danklinux.com can log client IPs. However, this endpoint is read-only and no user data is sent.

No obfuscated code, no hidden functionality, no suspicious patterns found.

Verdict

SAFE

DankMaterialShell is safe to use. Network activity is limited to user-facing features (weather, plugin registry). Privilege escalation follows standard Linux patterns. No data exfiltration or telemetry detected.
