Detailed analysis of potential network-related features:
  • Sentry crash reporting: DISK-ONLY. Custom Transport implementation replaces HTTP with local file write to $XDG_STATE_HOME/ghostty/crash/*.ghosttycrash

Crash Reporting — Privacy Analysis

Ghostty uses Sentry SDK but with a custom disk-only transport:

  • Crash data written to: $XDG_STATE_HOME/ghostty/crash/*.ghosttycrash
  • The standard HTTP transport is completely replaced with a file writer
  • "Crash reports are NOT automatically sent anywhere off your machine."
  • Users must manually opt-in to submit crash reports (separate action)

Privilege Requirements

Runs as a regular user process. Allocates PTY devices for shell sessions (standard terminal behavior). GPU access for rendering. No elevated privileges required.
