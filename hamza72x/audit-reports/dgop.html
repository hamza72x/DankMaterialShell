Purpose

Stateless system monitoring CLI + REST API. Reads CPU, memory, disk, network, GPU, and process metrics from Linux pseudo-filesystems (/proc, /sys) and presents data via CLI (pretty-printed or JSON) or a local REST API on port 63484. Provides a TUI mode (bubbletea-based interactive monitor).

Network Activity

ZERO outbound network calls. The program never phones home or contacts external servers.

Local API server (optional, user-started):
  • Binds :63484 when dgop server is run
  • Serves system metrics via REST API
  • The /docs page loads cdn.jsdelivr.net script in the browser (NOT fetched by the binary)

Process Execution

Only ONE exec.Command in the entire codebase:

  • nvidia-smi --query-gpu=temperature.gpu --format=csv,noheader,nounits
  • Purpose: Query NVIDIA GPU temperature
  • Risk: NONE — hardcoded binary name and flags, no user input, no shell invocation
  • Only runs if GPU driver is detected as "nvidia"

Security Concerns

  • None critical.
  • API server binds on all interfaces (:63484) not just localhost. On network-exposed machines, anyone could query system metrics. Acceptable for desktop use.
  • No authentication on the API server.

Verdict

SAFE

Zero outbound network calls. Single hardcoded exec.Command (nvidia-smi with fixed flags). All file operations are read-only from standard Linux system paths. No file writes anywhere. No telemetry, analytics, or data collection. No obfuscated code. All dependencies are mainstream, well-audited Go libraries.
