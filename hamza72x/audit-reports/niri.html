Networking Crates in Cargo.toml
ZERO. No reqwest, hyper, tokio, curl, ureq, or any HTTP/networking library present.

Network Activity

ZERO outbound network calls. Only local Unix socket IPC.

IPC mechanisms (all local):
  • WAYLAND_DISPLAY — local Wayland socket for client communication
  • NIRI_SOCKET — local Unix socket for niri IPC (niri msg commands)
  • DBus (via zbus) — local system/session bus only

No telemetry. No update checks. No analytics.

Build System & CI

  • build.rs: Minimal — only uses pkg-config to detect local libinput version. No URL fetches, no downloads.
  • CI: Standard Rust build/test pipeline. Release workflow vendors dependencies. No suspicious third-party GitHub Actions.
  • Smithay dependency: Pinned to specific git revision (prevents supply chain attacks via upstream changes)

Process Execution

Only spawns local processes:

  • systemctl — for session target management (local systemd)
  • dbus-update-activation-environment — propagates environment variables to DBus session (local)
  • User-configured spawn_at_startup commands — explicitly configured by user in niri config file
All spawned processes are either local system utilities or explicitly user-configured. No hidden or unexpected process spawning.

Security Concerns

  • None critical.
  • Written in Rust (memory-safe by default)
  • No networking crates means no attack surface for remote exploitation
  • All IPC is local Unix socket based
  • Significant community oversight (3k+ stars, active development)
